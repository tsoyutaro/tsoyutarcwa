# 正方格子のNV/ASR比較：2026-10-14保存結果

今回の無損失n=2.5モスアイでは、順計算による探索・最適化にはNVが有利。
同じ採用M=12、Nz=60、Q=384で、NVのウォーム順計算はASRの約2.28倍高速だった。
両方法とも全61波長の自己収束・エネルギー保存検査に合格している。
勾配を使う最適化の最終判断には、未完了の細分化監査を完了させる必要がある。

## 条件と順計算

- 正方格子、周期200 nm、高さ500 nm、先端／底部半径5/95 nm、線形の円錐台。
- 円錐台と半無限基板はn=2.5、無損失、波長非依存。空気から垂直x偏光入射。
- 図のM走査はNV/ASRともNz=60、Q=384を固定し、M=8/12/16/20を比較。
- Mは逆格子の各方向で−M～+Mまで保持する次数。正方のscalar harmonicsは(2M+1)^2。
- 図のRは全伝搬次数の合計反射率。%表示で、ゼロ次だけの反射率ではない。
- 全帯域の平均Rは400～700 nm、5 nm刻み61点の台形積分による波長平均。
- 自己収束の許容絶対変化0.00025、方法間比較0.001、|R+T−1|の許容値1e-6。

| 指標 | NV | ASR |
|---|---:|---:|
| 採用M / Nz / Q | 12 / 60 / 384 | 12 / 60 / 384 |
| 400～700 nm平均R | 0.731748% | 0.728053% |
| 全61波長でM→20の最大変化 | 7.908e-5 | 5.497e-5 |
| 全61波長でNz→100の最大変化 | 3.586e-5 | 3.739e-5 |
| 全61波長でQ→512の最大変化 | 4.196e-6 | 6.677e-7 |
| 全61波長で三軸同時細分化の最大変化 | 4.097e-5 | 1.545e-5 |
| 全329順計算ケースの最大 abs(R+T−1) | 1.041e-12 | 1.350e-12 |

両方法の全61波長での最大差は8.718854e-5（0.00871885パーセントポイント）、
最大差の波長は700 nm。指定した許容値内で一致している。
ASRのRが低いことだけでは高精度とは判断できない。
ASRも細分化に対して安定し、一部の指標ではNVより変化が小さい。
今回のNVの優位性は、同じ収束判定に合格した条件での計算コストにある。

## 時間と勾配

H100、complex128、監査11波長の平均R目的関数を3回測定した中央値。
ウォームアップは除外した。下記は1波長の時間ではない。

| 指標 | NV | ASR | NVの速度比 |
|---|---:|---:|---:|
| 順計算 | 105.334 s | 240.567 s | 2.284倍 |
| 順計算＋高さ／底部半径AD | 298.342 s | 1779.082 s | 5.963倍 |

勾配の時間は基準M=12の実測値。ASRは層checkpointによる再計算を含み、NVは含まない。
この値は現在の実装における測定値であり、一般的な両理論の速度差ではない。
measured_cost.png/svgには3回の中央値と最小～最大の範囲を示した。

両方法の基準条件で、高さ・底部半径ADは中央差分hおよびh/2に一致した。
ただし勾配の細分化監査は、NVがM=20でCUDAメモリ不足、ASRが細分化監査へ進む段階で
KeyboardInterruptとなっている。両者の勾配のメッシュ収束は未検証。

ASRの正式な保存statusはinterruptedで、集約comparison.jsonの正方推奨は
insufficient_evidenceのまま。順計算の証拠がそろっていることと、全監査の完了を区別した。

追加結果では六方ASRの勾配監査は合格している。六方NVはM=20でのメモリ不足が残る。
正方における勾配最適化の確定とは別の結果である。
