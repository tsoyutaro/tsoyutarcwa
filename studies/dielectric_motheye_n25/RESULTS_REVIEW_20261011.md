# 2026-10-11：保存済みGPU結果の確認と修正

対象は`results/comparison.json`と
`../pmma_cr_motheye/results/pmma_cr_motheye_convergence.json`。
旧GPU結果はそのまま保存し、修正版で上書きしていない。

## 判定

PMMA+Crは、指定した判定波長・許容値の範囲では適切。
n=2.5のNV/ASR比較は、正方ASRの非物理的な応答、六方の方法間不一致、
六方ASRの勾配監査のメモリ不足があり、最適化手法の確定に使えない。

| 対象 | 保存された条件 | 状態と判断 |
|---|---|---|
| PMMA+Cr 六方ASR | M=18、Nz=80、Q=384 | `converged`。最終61波長完了、R/T/Aは受動性の範囲内 |
| n=2.5 六方NV | M=6、Nz=40、Q=256 | 旧判定点では収束、勾配監査合格。平均R=0.594652% |
| n=2.5 六方ASR | M=6、Nz=40、Q=256 | 旧判定点では収束。平均R=0.507403%。上位M=12の勾配監査でOOM |
| n=2.5 正方NV | M=4、Nz=40、Q=256 | 旧判定点では収束、勾配監査合格。平均R=0.736846% |
| n=2.5 正方ASR | 最後の設定M=12、Nz=80、Q=384 | `nonphysical_results`。値を採用しない |

平均値は400–700 nm、5 nm刻み61点の台形積分による波長平均。
太陽光・光源スペクトルの重み付けはしていない。

### PMMA+Cr

平均R=1.403412%、T=0.854296%、A=97.742292%。
半無限の無損失PMMA基板への透過を含み、A=1−R−T。
高さ500 nm、PMMA先端／底部半径5/65 nm、Crの半径方向被膜30 nm、
頂部・谷底膜30 nm、周期200 nmの六方格子、垂直x偏光。

上限側の2区間の最大R/T/A変化は、Mで約0.000288、Nzで約0.000293、
Qで約0.0000473であり、許容値0.005（0.5パーセントポイント）より小さい。
最終スペクトルも滑らかで受動性違反はない。
ただし三軸の収束確認は400/550/700 nmに限る。61波長すべてのメッシュ誤差保証ではなく、
R+T+A=1も体積吸収積分との独立照合ではない。

より厳しい全帯域評価へ進む場合のコマンドは次のとおり。
共有ソースのハッシュが変わるため、従来の結果とは別出力先で実行する。

```text
python run_pmma_cr_motheye_convergence.py --device cuda --anchor-wavelengths 400:700:25 --tolerance 0.001 --run-final-spectrum --output-root studies/pmma_cr_motheye/results/dense_anchors_v2
```

### n=2.5 六方

NVとASRの反射率差は645 nmで最大0.00168824、すなわち0.168824パーセントポイント。
許容値0.001（0.1パーセントポイント）を超える。
旧判定点400/430/436/495/505/550/700 nmでは、この領域を確認していなかった。
単独の`converged`表示だけでは両方法の一致を意味しない。

ASRの上位次数の勾配計算ではPyTorch割当43.07 GiBに達し、約46.38 GiBのGPUでOOM。
大きな写像・Fourier積分・因数分解・固有値問題の計算グラフを全層分保持することが問題。
保持次数を下げて監査を省くのではなく、層ごとに逆伝播時の再計算を行う方式へ変更した。

### n=2.5 正方

133ケース中91ケースで無損失のエネルギー保存などに違反。
最大の例はM=12、Nz=80、Q=128、436 nmでR=97.2487、T=312.7493。
これは回折効率の割合であり、97%や312%という表示ではない。

CPUでも従来の写像を使うM=12、Nz=20、Q=128、550 nmで
R=2.59921、T=0.626753、R+T−1=2.22596を再現した。
CUDAやGPU性能の問題ではない。
底部に近い半径92.75 nmの層では、界面で使う電場変換のC2vセクターの
2ノルム条件数が約7.13×10^11（M=12、Q=128、G=0.03）。
従来の二方向の座標圧縮で変換が悪条件になり、線形方程式による界面接続が不安定になる。

## コード修正

1. 正方格子の既定ASRをD4対称な放射状の円境界写像`radial`へ変更。
   周期境界を保ち、二方向の過度な同時圧縮を避ける。
   円周上の浮動小数点誤差で材料判定が非対称にならないよう、材料境界は計算座標で判定する。
2. 対称性縮約を使うASRの形状勾配で層ごとのactivation checkpointを導入。
   同じ層モードを逆伝播時に再生成し、大きな中間グラフの全層同時保持を減らす。
   順計算のみの場合は再計算方式を使わない。
3. 判定波長に475/600/645/650 nmを追加。既定Q候補を256/384/512へ変更。
4. `--run-final-spectrum`では全最終波長でM/Nz/Qを個別に上限へ増やした条件と、
   三軸同時に上限へ増やした条件を検査。
   不合格なら`final_spectrum_not_converged`として時間・勾配監査へ進まない。
5. 勾配監査の再開識別にcheckpoint設定を追加。OOM時には例外の参照グラフを解放する。

共有ASRの従来の六方写像については、3半径で修正前との座標・ヤコビアンの完全一致を確認。
PMMA+Crの既定`outer`写像の数式・材料分布・接続は変えていない。

## ローカル検証と限界

- n=2.5の17単体テスト、PMMA+Crの9単体テストが合格。
  エネルギー保存、回折が開く波長・閾値、有限差分との形状勾配比較、再開、
  偽の収束や方法間不一致を採用しない判定を含む。
- 既存の六方写像検証31チェックが合格。Q=256/384/512のD6対称性・
  独立したNumPy実装との一致・半径勾配を確認。
- 正方の上記92.75 nmの変換条件数は、新写像で約5.70×10^3へ改善。
  最小ヤコビアンは約0.03046で正。円周上の格子点を含む材料マスクも鏡映対称。
- M=2、Nz=4、Q=64の両格子で、checkpoint有無によるRと高さ／半径勾配が一致。
  逆伝播用に保存されたテンソルサイズの合計は六方170,816,016→300,824 byte、
  正方152,942,500→790,376 byte。これは重複を含むテンソル合計で、GPUピーク値ではない。
- `results/local_repair_smoke`は550 nmだけ・許容値0.2の処理確認。
  全波長メッシュ検査と監査までの実行経路を確認するためのもので、光学精度の根拠にしない。

新写像はM=12のCPU計算でエネルギー保存を回復するが、低い積分精度では反射率が不安定。
550 nm、Nz=20、M=12でQ=128のR=0.0257335、Q=256のR=0.00659523、
Q=384のR=0.00614481、Q=512のR=0.00665877。
Q=256/384/512ではabs(R+T−1)≦1.3×10^-12。
NVの同じM/Nz、Q=256のR=0.00834704とも未一致。
エネルギー保存の回復を、そのまま光学精度の収束と解釈しない。
Gの変更だけで都合のよい値を選ばず、M/Nz/Qと両方法の一致を改めて検査する。

ローカルはPyTorch 2.8.0+cpu。新しい全帯域GPU結果やGPUのピークメモリはまだ得ていない。
