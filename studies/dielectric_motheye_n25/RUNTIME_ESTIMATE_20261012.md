# 3点の初期収束走査と所要時間（2026-10-12）

初期のM/Nz/Q走査を400/550/700 nmの3点へ変更した。
3点だけでは、旧GPU結果で645 nmに見つかったNV/ASR差を見落とすため、
最終61点の三軸別・三軸同時の細分化検査を保持する。
最終チェックで不合格になった波長を自動で追加し、最大2回再走査する。
時間と形状勾配の監査は、従来の11点を維持する。

## 保存時点からの残り時間

使用した進捗は`results/repaired_v2`の六方NVの429ケース。
M=6/Nz=60/Q=384で最終61点まで計算済み。
細分化のM・Nz・Q単独チェックが合格し、M=16/Nz=100/Q=512の同時細分化は695 nmまで完了。
時間・勾配監査と、他の3グループは保存時点では未開始。
遠隔の現在の実行プロセスを直接取得したものではない。

| 仮定した採用条件 | 11点の初期走査 | 3点の初期走査 | 短縮 |
|---|---:|---:|---:|
| ASRがM=6/Nz=60で成立 | 18.40時間 | 16.18時間 | 2.22時間 |
| ASRがM=10/Nz=60で成立 | 25.31時間 | 22.90時間 | 2.41時間 |
| ASRがM=14/Nz=80で成立 | 42.61時間 | 40.63時間 | 1.98時間 |

通常の目安は残り16〜23時間程度、余裕を見て17〜25時間。
高次数が必要な場合は約41時間。自動追加の再走査やGPUの負荷変動で延びる。
これらは光学精度がすべて通り、全監査まで実施する場合の想定。
候補不足などで監査を省略して終了する場合は短くなるが、検証成立とは異なる。

初期走査の波長数は約73%減るが、すでに済んだ六方NVの計算時間は取り戻せない。
最終61点の高次数の計算と勾配監査は減らしていないため、残り全体の短縮は約2時間。
基準条件に加えM/Nz/Qの各上限と三軸同時上限を61点で比較する部分が大きい。

## 計算根拠

`estimate_n25_motheye_runtime.py`は標準ライブラリのみを使い、光学計算を実行しない。

- 六方NVは新しいH100のM別の秒／層の中央値を使用。
- 六方ASRの順計算は、過去のGPU結果をもとにNVの約1.56倍として推定。
- 正方は過去のGPU結果からM=14/16を外挿し、実行条件の差を係数1.5で補正。
- 初期走査は2サイクルで採用条件が安定する想定。各ケースのキーを列挙し、
  保存済みの完了ケースを差し引く。追加波長の再走査回数は予測に含めない。
- 順計算のウォームアップ＋3測定、8通りの有限差分、勾配のウォームアップ＋3測定、
  上位M/Nz/Qの3勾配監査を数える。監査波長は11点。
- NVの勾配計算は順計算の1.6倍、checkpointを使うASRの勾配計算は3〜4倍として推定。
  新方式のGPU勾配時間は未実測。
- Q=512の順計算費用はQ=384に近いと仮定。GPU負荷変動やファイル出力などの費用は含めない。

生データは`results/runtime_estimate_3_anchors.json`と
`results/runtime_estimate_11_anchors.json`に保存した。

## 再開

遠隔の実行を停止してから`studies/dielectric_motheye_n25/compare.py`を更新し、
同じ出力先で再開する。今回の修正対象は走査・監査の波長設定と判定の進め方。
`model.py`や`rcwa_ext`のハッシュは保存済み`repaired_v2/plan.json`と一致している。

```text
python run_n25_motheye_comparison.py --device cuda --orders 4,6,8,10,12,14,16 --slices 40,60,80,100 --grids 256,384,512 --anchor-wavelengths 400,550,700 --run-final-spectrum --output-root studies/dielectric_motheye_n25/results/repaired_v2
```

進捗ファイルを更新した後に見積もりだけ再計算する場合：

```text
python estimate_n25_motheye_runtime.py --output-root studies/dielectric_motheye_n25/results/repaired_v2
```

CPUの小規模テストで3点走査・最終確認・645 nmの自動追加・不合格の保持を検証した。
GPUの全帯域再計算をローカルで実施したという意味ではない。
