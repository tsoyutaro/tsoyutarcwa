# Ag単体550 nm：NV法のQ依存性・層別パワー・励起モードの診断

計算用フォルダの直下に `run_ag_nv_m14_diagnostics.py` を置き、次を実行する。既存の `rcwa_ext`、`studies/transition_metals_nv/runtime.py`、Ag.csvなどと同じフォルダ構成が必要。

```bash
python -u run_ag_nv_m14_diagnostics.py \
  --device cuda:0 \
  --order 14 --wavelength-nm 550 \
  --slices 210 \
  --grids 384,512,768,1024 \
  --output-root studies/ag_nv_m14_diagnostics/results/M14_Nz210_Q384-1024_550nm
```

固定する条件はAg単体、周期200 nm、高さ500 nm、先端半径5 nm、底部半径95 nmの直線プロファイル、三角格子、垂直入射・x偏光、半無限Ag基板、complex128、D6のE1-x成分、NV法、Lanczosなし。変えるのは法線場のサンプリング点数Qのみ。Qはフーリエ次数やモスアイの層数ではない。

通常の次数走査は内部場を保存しないため、この診断用ファイルを使う。既存のNV因数分解・固有値問題・モードを変えず、各層の全空間行列を解放し、縮約したE/H/kzから入射源1本に対する内部場を復元する。既存の半S行列との反射・透過振幅の一致も確認する。増加する診断用メモリは主に縮約行列であり、全層の全空間P/Qや全ての入射源の内部場を保持しない。

## 失敗と再開

- 非物理値を切り捨てたり0〜1へクリップしたりしない。診断結果として保存し、次のQへ進む。
- Qごとに別プロセスで実行する。OOMや計算例外が起きても次のQへ進む。
- 同じコマンドを再実行すると完了済みQを再利用する。失敗済みQも通常は再試行しない。失敗を再試行したい場合は `--retry-failures` を付ける。
- 同じ出力先でQを追加できる。M、Nz、材料データ、計算ソースなどが変わった場合は新しい出力先を使う。
- `--dry-run` は設定とAg.csvの波長範囲だけを確認し、電磁場計算やファイル作成をしない。
- `--plot-only` は保存済みデータから図を作り直す。`--no-plots` は作図を省略する。

## 出力

| ファイル | 内容 |
|---|---|
| `Q_summary.csv` | 各QのR、全A、モスアイA、基板A、負の吸収層数、診断結果 |
| `Q_changes.csv` | 隣接する保存済みQ間のR・Aの変化。欠測がある区間は比較しない |
| `summary.json` | 全Qの設定・完了/失敗状況・診断値 |
| `Q512/far_field.json` など | 通常の半S行列から求めたR・A・基板に入るパワー。内部場診断に失敗しても、ここまで完了していれば保存する |
| `Q512/operator_diagnostics.csv` など | 各層の損失行列の最小固有値、負の固有値の数、固有ベクトル行列の条件数、固有問題の残差。層の組立中にも逐次保存する |
| `Q512/layer_power.csv` など | 各層の上端・下端の正味下向きパワー、層内の吸収、独立な損失体積積分、負の損失固有空間の寄与 |
| `Q512/excited_modes.csv` など | 全層・全モードの伝搬定数、前進/後退振幅、電場ノルムによる励起の指標、打切り付近のフーリエ成分比 |
| `figures/Q_dependence.png` / `.svg` | QによるR・A・モスアイAの変化 |
| `figures/layers_modes_Q512.png` / `.svg` など | 深さ方向のパワー、層ごとの吸収、励起モードの分布、負の損失成分の励起 |

表のQ512は例。指定した各Qのフォルダを作る。層番号は1始まり、深さはモスアイ上端0 nmから下端500 nm。`layer_absorptance`や`flux_top`は入射パワーを1とした値、`layer_absorptance_pp`はパーセントポイントである。

各層の吸収は `flux_top − flux_bottom`。負なら、その層の数値解は正味の増幅を示している。モスアイ全層の吸収と基板吸収の和が `1−R` に一致するかも保存する。金属基板は半無限なので遠方透過率Tは0だが、基板表面に入ったパワーは基板の吸収として別に保存する。

## 体積積分の独立な検査

内部場を `dE/dz=iωPH`、`dH/dz=iωQE`、パワーを `Re(E†GH)/2` と表す。Gは電場・磁場の縮約基底の間のポインティング形式である。このとき、深さあたりの損失は

`ω/2 × {E† Im_H(GQ) E + H† Im_H(G†P) H}`

となる。これを各層内でGauss積分し、境界パワー差と比較する。初期16点（`--quadrature`で変更可）から必要に応じて32/64/128点へ増やす。積分値を境界パワー差へ合わせる補正はしない。

`negative_electric_sector`と`negative_magnetic_sector`は、損失行列の負の固有値に属する成分へ実際の場を射影した体積積分。単に負の固有値があることだけでなく、その成分を実際の場が励起しているかを確認できる。これは離散化したNV系の診断値であり、実材料に利得があるという意味ではない。

## モードの読み方

- `kz_real`、`kz_imag` は真空波数で規格化した伝搬定数。
- 前進振幅は層の上端、後退振幅は下端での値。減衰波の逆伝搬を使わずに復元する。
- `electric_mid_norm2_proxy` は層中央での各モードの電場ノルムによる励起の指標。固有ベクトルの任意のスケールに依存しない。
- モード間の干渉があるので、この指標や自己パワーを足して全パワーとみなしてはいけない。
- `edge_harmonic_fraction` は各モードの電場ノルムのうち、D6閉集合の次数 `max(|m|,|n|,|m−n|) >= 0.8 M` にある割合。大きいことだけで擬似モードと断定しない。励起強度、Q依存性、損失への寄与などと合わせて調べる。
- モード番号は各層内での並び順であり、層やQが違うと同じ番号が同じモードを意味するとは限らない。

`physical_result`はパワー値の物理範囲と各層の非負吸収の検査、`diagnostic_checks_passed`は境界場・既存S行列・体積積分の整合性の検査であり、別の判定である。後者がTrueでも前者がFalseなら「非物理的な離散化解を整合的に再構成できた」という意味で、収束・物理的正しさの合格ではない。Q依存性が小さいことだけでも真値への収束は保証しない。

## 検証範囲

小規模なCPUの2D NV計算で、既存の内部場APIから得た全層の上下端ポインティング量と比較し、一致を確認した。損失体積積分と境界パワー差も一致する。非物理値の保存、OOM後の継続、再開、Q追加、設定検査も自動テストで確認した。本番のM=14・210層・各QのGPU計算は、このファイルを配置した計算機で実行する。
