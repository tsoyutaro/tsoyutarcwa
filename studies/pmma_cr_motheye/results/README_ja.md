# 保存結果について

本番計算の結果はこのフォルダ直下に生成される。
現時点では既定のGPU本計算は実行していない。

`validation_*`フォルダは作成時に使ったCPU動作確認用であり、
物理的な収束値・推奨設計の根拠として使用しない。
低次数・少数層で、保存・再開・図生成・未収束時の停止を確認した。
`validation_pipeline`の大きな許容値0.5は、スペクトル出力経路を試すための値であり、
本番の許容値0.005とは異なる。これらのフォルダはGit対象から除外している。

本番結果を確認するときは、このフォルダ直下の
`pmma_cr_motheye_convergence.json`の条件とステータスを参照する。
