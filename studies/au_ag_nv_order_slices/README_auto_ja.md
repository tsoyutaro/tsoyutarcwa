# Au・Ag：層数確認から次数走査までを1回で実行

追加ファイルはプロジェクト直下の `run_au_ag_nv_layer_then_order.py` です。
既存の `run_au_ag_nv_order_slices.py`、Au/Ag NVランナーとソルバーを使用します。
ソルバー、複素数精度、形状、材料データは変更していません。ZIPは不要です。

```bash
python -u run_au_ag_nv_layer_then_order.py \
  --device cuda:0 \
  --cases Au:700,Ag:550 --structures both \
  --slices 180,210,240 \
  --start-order 4 --step 2 --max-order 36 \
  --grid 512 --tolerance 0.005 \
  --output-root studies/au_ag_nv_order_slices/results/auto_Nz180-240_M4-36_Q512
```

1. 各材料・構造・波長についてM=36、Nz=180→210→240を確認します。
2. 180→210と210→240の両区間でR・全Aの絶対差がそれぞれ0.005以下
   （0.5パーセントポイント以下）の組だけ、Nz=240、M=4,6,…,36を実行します。
3. 各ケースを既存の独立ワーカープロセスで実行し、メモリを解放します。
4. 計算に失敗した組の高層数を省略し、次数走査中の失敗後は高次数を省略します。
   別材料・別構造は続行します。層数基準未達や欠測の組では次数走査を行いません。

既定では `studies/au_ag_nv_order_slices/results` 以下の `checkpoint.json` を検索します。
保存済みの180/210/240層および次数走査結果のうち、ソルバー・材料ハッシュ、
形状、Nz/Q、波長、デバイス等の固定条件が一致するものを再利用します。
開始次数・次数刻み・判定閾値は計算値を変えないため、再利用時の同一性比較から除外します。
計算に用いた材料CSV等の絶対パスも一致が必要です。丸められたCSVや端末ログからは再利用しません。
同一条件の保存済みパワーに1e-10を超える相違がある場合、その点を再計算します。
確認段階で得たM=36/Nz=240は次数走査に引き継ぎ、重複して計算しません。

検索場所を追加・指定する場合は `--reuse-root PATH` を繰り返します。
明示した場合はその場所のみを検索します。現在の出力先のチェックポイントも再利用します。
別の場所の失敗履歴は引き継がず、成功値のみを再利用します。
現在の出力先で記録された失敗は再実行時も保持します。明示再試行は `--retry-failures` です。

同じコマンドの再実行では成功済み条件を飛ばします。設定やソースが変わる場合は新しい
`--output-root` を使用してください。Ctrl+Cで中断し、同じコマンドで再開できます。

出力：

- `layer_gate.csv`：各材料・構造の層数基準合否と次数走査の状態。
- `comparison_changes.csv`：層数間・次数間のR/A/T変化（ポイント）。欠測を飛び越えて比較しません。
- `layer_cases.csv`、`order_cases.csv`、`all_cases.csv`：各計算値。全結果では同一条件の重複を除きます。
- `workflow_summary.json`：合否、完了・失敗、再利用元と計算条件の記録。
- `layer_check/`、`order_sweep/`：既存ランナー形式の保存結果。
- `figures/Au_metal_wl700_NV.png/.svg` 等：上段が層数依存、下段が次数依存、各段はR/A/Tの3列。

PMMA複合のNz=240は形状部分240層で、上面キャップを含む総層数は241です。
今回の層数判定は指定波長・M・Qでの隣接差に基づく実用基準です。
全波長、Q方向、厳密な誤差上限の保証ではありません。
完了状態は合否とは区別し、科学的な未収束やOOMのみは終了コード0、
通常の計算失敗があれば他の組を処理した後に終了コード1になります。
次数方向のR/A末尾2区間の合否も集計します。既存ランナーのreport.jsonとは
判定対象（単体の吸収成分など）が異なる場合があります。

確認のみ：`--dry-run`。GPUなしの検証：

```bash
python -m unittest validation.test_au_ag_nv_layer_then_order -v
```
