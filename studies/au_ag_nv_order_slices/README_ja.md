# Au 700 nm / Ag 550 nm：NV法の次数×層数比較

既存の `run_gold_motheye_order_nv.py` と `run_cu_ag_al_motheye_order_nv.py` を変更せずに呼び出す追加ドライバーです。
新規にサーバーへコピーする実行ファイルはプロジェクト直下の `run_au_ag_nv_order_slices.py` です。ZIPは不要です。

```sh
cd /home/7/uq06557/common2/20260813/tsoyutarcwa
python -u run_au_ag_nv_order_slices.py \
  --device cuda:0 \
  --cases Au:700,Ag:550 --structures both \
  --orders 30,32,34,36 --slices 60,90,120 --grid 512 \
  --tolerance 0.005 \
  --output-root studies/au_ag_nv_order_slices/results/M30-36_Nz60-120_Q512
```

最大48条件：2材料×2構造×4次数×3層数。単体のみなら `--structures metal`、PMMA複合のみなら `--structures pmma`。
周期200 nm、高さ500 nm、三角配列、正入射x偏光、complex128、Lanczosなし、D6源縮約、Redheffer接続。
材料データと形状は従来のNVランナーの既定設定を使用します。Auは測定CSV、Agは添付Ag.csv。
単体は底面半径95 nm・先端半径5 nm・半無限同一金属基板。
PMMA複合はコア底面半径65 nm・先端半径5 nm、側面・上面・谷部金属膜30 nm、半無限PMMA基板。
PMMA複合のNzは形状部分の分割数で、上面キャップ1層を加え、総層数は61/91/121です。

## OOM・失敗時の動作

各材料・構造・波長を独立に扱い、Nzを60→90→120、各NzでMを30→32→34→36の順に実行します。
各計算は既存ランナーの別プロセスで実行し、終了時にGPUメモリを解放します。

M=m、Nz=nでOOMになった場合、同じ材料・構造・波長で **M>=mかつNz>=n** の未計算条件を省きます。
例えばM34/Nz90で失敗したら、M36/Nz90とM34/36/Nz120を省き、M30/32/Nz120は続行します。
別材料・別構造には失敗境界を適用しません。
非物理値などの通常エラーもOOMと区別して保存し、同じ保守的な省略規則で他条件へ進みます。
この規則はユーザー指定による負荷の打切り方針で、失敗領域の数学的な証明ではありません。
非物理値は次数に対して非単調な場合もありますが、上側条件は試しません。

成功条件、失敗条件、省略条件を随時保存します。同じコマンドを再実行すると、成功済み条件と記録済み失敗領域を飛ばします。
GPUの空きが増えた等で失敗領域を再試行したい場合に限り、同じコマンドに `--retry-failures` を追加します。
Ctrl+Cでは中断します。OOMのみの場合は全体を最後まで処理して終了コード0、通常エラーを含む場合は最後まで処理した後に終了コード1です。
プロセスが結果を保存できず終了した場合は原因を断定せず、通常エラーとして記録します。

## 保存先

指定出力ルート直下：

- `all_cases.csv`：成功した全条件のR/T/A、モスアイ吸収・基板吸収、計算時間、GPUメモリ。
- `case_status.csv`：全48条件の成功・OOM・通常エラー・省略の区別。
- `comparison_changes.csv`：次数方向と層数方向の隣接R/A/T差。未計算点を飛び越す比較はしません。
- `batch_summary.json`、`batch_checkpoint.json`：継続状況・失敗境界・設定。
- `metal/au/wl700/Nz60/` 等：既存ランナー形式の各条件のチェックポイント・全結果。
- `metal/au/NV_order_slices_wl700.png/.svg` 等：材料・構造ごとの比較図（計4組）。上段が次数依存、下段が層数依存、左R・右A。

`--tolerance 0.005` は絶対差0.5パーセントポイントです。CSVのR/T/A自体は0〜1の比率です。
比較CSVのpasses_R_AはRと全Aの両方にこの基準を適用します。
各Nzフォルダーの従来report.jsonは既存の判定を保持し、単体では基板・モスアイ別の吸収も判定するため、比較CSVと判定対象が異なります。
試験範囲全体での厳密な収束を自動認定するものではありません。

条件確認だけなら `--dry-run`。保存済み結果から図を再作成する場合は、同じ出力ルートを指定して `--plot-only`。
描画ライブラリが未導入でも計算結果を保存し、描画エラーをplot_error.txtに残します。描画を省く場合は `--no-plots`。

## 検証

```sh
python -m unittest validation.test_au_ag_nv_order_slices -v
```

OOM後の他条件継続、次数・層数の省略範囲、通常エラーとの区別、再開・明示再試行、欠測比較の除外を、GPUを使わず模擬失敗で確認します。
