# 単一偏光計算の検証

- `validation.json` / `cases.json`: 27ケース×s/p、計54条件の局所複素振幅・全次数R_m/T_m・R/T/A合計の比較。各層の固有値呼出しのバッチ数が1であること、適応位相平均の停止点数が同じであることを確認。
- `control_tests.json`: 自動制御23件のテスト。p/s選択・設定変更拒否・再開を含む。
- `integration_checks.json`: 実RCWAによるp専用実行。キャッシュなしと旧s/pキャッシュありの両方で、従来のp行と全物理フィールドが一致。従来s/pキャンペーンの再開と、明示的なboth指定も検証。
- `installation_checks.json`: studyへの配置、配置先からのp専用実行、元のPython・過去の結果の保存確認。

CPUのみで実行しました。M240/Nz30の照合では、元のs/p計算のTorch/MKLバッチsolveがエラーとなったため、両経路の線形solveを診断プロセス内でSciPyに置き換えています。実運用ソースは変更していません。有限M/Nzでの一致検証であり、次数・層数の収束証明やGPU速度測定ではありません。
