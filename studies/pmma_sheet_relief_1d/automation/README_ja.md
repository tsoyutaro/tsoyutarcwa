# 収束またはOOMまでの自動実行（2026-11-15）

`converge_until.py` は、従来の `run.py` と `converge.py` の比較式を使い、次数または層数を上限なしで増やします。**連続2回の比較が収束条件を満たしたら終了、OOMなら未収束として終了**します。1つの解像度ごとに別プロセスで計算し、終了時にCUDAコンテキストを解放します。

## 導入

v2を使用している既存RCWAルートで更新ZIPを展開してください。追加先は `studies/pmma_sheet_relief_1d/automation/` です。既存の計算本体・材料ファイル・結果フォルダは変更しません。

計算キャッシュのソース署名はstudy直下のPythonファイルを含むため、機能をサブフォルダに置きました。**既存の物理ソース署名と点キャッシュのキーは変わりません。** 更新前と条件・材料・device・環境が一致する点は、従来の共通キャッシュから再利用します。

## 次数を自動で増やす

既存RCWAルートから実行します。M96→112→128→144→160→…、Nz960固定、3波長・両周期・空気/水・s/pです。最大次数の指定はありません。

```bash
python studies/pmma_sheet_relief_1d/automation/converge_until.py \
  --axis order --start 96 --step 16 \
  --coating gold --device cuda --slices 960 \
  --wavelengths "400,550,700" --periods "3720,3920" --voids both \
  --geometry-mode scaled --gold-nm 50 --tolerance 0.001 \
  --phase-tol 0.00005 --phase-max 262144 \
  --output-dir studies/pmma_sheet_relief_1d/results/gold_gpu_auto_orders_Nz960
```

まず700 nmだけに絞る場合は `--wavelengths "700"` とし、**別の出力先**を使います。700 nmでの収束は400/550 nmの収束を保証しません。

一方の軸は固定です。次数について収束しても、層数については別途確認が必要です。OOMはメモリの限界を示すもので、最後に成功したMの収束を保証しません。

## 層数を自動で増やす

例はM128固定、Nz960→1920→3840→…です。固定するMは、実際の次数収束結果に合わせて指定してください。

```bash
python studies/pmma_sheet_relief_1d/automation/converge_until.py \
  --axis slices --start 960 --factor 2 \
  --coating gold --device cuda --order 128 \
  --wavelengths "400,550,700" --periods "3720,3920" --voids both \
  --geometry-mode scaled --gold-nm 50 --tolerance 0.001 \
  --phase-tol 0.00005 --phase-max 262144 \
  --output-dir studies/pmma_sheet_relief_1d/results/gold_gpu_auto_layers_M128
```

`--step` は整数の加算、`--factor` は倍率（端数切上げ）です。両方を同時指定できません。省略時は次数が+16、層数が×2。開始値省略時はそれぞれ96/960です。自動で動かす軸の `--order` または `--slices` は併記せず、`--start` で指定します。

必要な場合だけ `--max-value 160` のような明示的な上限を追加できます。上限省略時に、暗黙の最大M/Nzはありません。

## 判定と停止

従来と同じ判定を使います。

- 全条件の各次数R_m/T_m、合計R/T/A、反射20°以内/外の**最大絶対差**を比較。
- 直近の連続2回が `--tolerance` 以下。
- 位相平均が収束し、両方の位相誤差指標が許容値の1/4以下。

`0.001` はパワー比で、百分率表示の差では0.1ポイントです。例えばM96/112/128の2比較が両方合格すればM128で終了します。合格の適用範囲は、指定した波長・材料・周期・溝・偏光・固定層数に限ります。

| status / 終了コード | 意味 |
|---|---|
|converged / 0|連続2回合格|
|limit_reached / 2|指定した任意上限に到達、未収束|
|oom / 3|CUDA/CPUの明示的なメモリ確保エラーで停止|
|child_error または error / 4|固有値計算・受動性・設定・I/Oなど、OOM以外のエラー|
|phase_unconverged / 5|位相平均が未収束。次数を上げ続けず停止|
|interrupted / 130|Ctrl+Cによる中断|
|killed_possible_oom / 137|子プロセスが強制終了。OOMとは断定しない|

OOM以外のエラーはOOMと区別します。位相平均が未収束なら、新しい出力先で位相点数・誤差設定を見直してください。OSやスケジューラがジョブ全体を強制終了した場合、最後の状態保存は保証されませんが、保存済みの結果と再開マーカーは残ります。

## 再開と記録

**同じコマンド・同じ出力先で再実行**すれば、完了済みの次数/層数はファイルのハッシュを確認して再利用します。失敗した解像度を再試行し、その中でも計算済みの波長点は共通キャッシュから再利用します。OOM直後に再実行すると、同じ解像度で再びOOMになることもあります。

許容値・波長・形状・材料・固定軸・開始値・増分・ソースなどが変わる場合は新しい出力先を使います。任意の `--max-value` のみは同じ出力先で延長できます。同じ出力先への同時実行はロックで防ぎます。

| ファイル | 内容 |
|---|---|
|auto_campaign.json|固定設定・ソース・材料・環境の署名|
|convergence.json|現在状態、最後に完了した解像度、試行中/停止した解像度、停止理由|
|adjacent_changes.csv|完了した隣接解像度の比較値と合否|
|logs/order_96.log など|子プロセスの標準出力・例外全文|
|order_96/ など|従来と同じスペクトル・各次数・設定|
|order_96/.auto_complete.json など|再開用の完了マーカーと結果ファイルのハッシュ|

従来の手動収束結果フォルダを自動実行の出力先に上書きすることは避け、新しいフォルダを指定します。既存の点キャッシュは出力先を変えても共有します。
