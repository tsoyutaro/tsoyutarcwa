今回の `run_all.py` の予定した 140 計算は全て完了しています。
`verification_rounds: []` は、最初の三軸比較で条件を満たさず、候補の組み合わせの再確認に進まなかったことを表します。
この実行では解析的係数との照合もまだ行われていません。

TE は最後の二比較で全波長・三軸とも許容差内です。TM は次が主な不合格箇所です。

全比較の `passivity_bounds_pass` は true です。これは値の範囲の検査であり、収束や独立したエネルギー検証を保証しません。

## 次の実行

今回の一次元形状は、各高さスライスで中心配置の矩形です。
幅比 f の矩形の Fourier 係数 `f*sinc(m*f)*exp(-i*pi*m)` を直接計算できます。
`epsilon` と `1/epsilon` の両方をこの解析式で求め、同じ Cartesian Li 因子分解を使います。
これにより横方向の材料サンプリング誤差を除き、M と Nz の収束を分けて検討します。有限 M と有限 Nz の近似は残ります。

Linux のリポジトリ直下で実行：

```bash
python3 studies/gold_grating_1d/run_analytic.py --device cuda
```

初期値は M=[32,40,48,56]、Nz=[180,220,260,300]。
波長・構造・測定金データ・許容差は既存の `config.json` から読み、係数の計算方法だけを実行時に `analytic` にします。
最初の二軸比較は最大 49 波長計算です。各計算から TE/TM の両方を取得し、候補の組み合わせの再確認が追加されます。

出力先は `results/analytic_search/` です。
従来のサンプリング係数による結果と、新しい解析的係数による結果は計算条件が異なるため、この新しい出力先で評価します。
新しい解析的計算の保存済み結果は、以後の延長や再実行で再利用します。
`grid_used` は null で、共通のケース情報にある `grid` の数字はこの計算には使いません。

候補は、各軸で二回連続の変化が許容差内となり、その後の全比較も許容差内となる点から選びます。
さらに候補の同じ M/Nz の組み合わせで両軸を再確認し、両軸とも最大値の基準とも比較します。
合格しなければ `not_converged` とし、推奨値を出しません。

未収束なら、例えば次のように範囲を延長できます。

```bash
python3 studies/gold_grating_1d/run_analytic.py --device cuda \
  --orders 32,40,48,56,64 \
  --slice-values 180,220,260,300,340
```

構造・計画だけを確認する場合は `--prepare-only`、保存済み結果だけを判定する場合は `--report-only`。
範囲を延長した後、引数なしで再実行しても、保存した探索範囲を引き継ぎます。
作図や時間・メモリ・選択層の条件数の出力は既存と同じです。再作図：

```bash
python3 studies/gold_grating_1d/plot.py \
  studies/gold_grating_1d/results/analytic_search/checkpoint.json
```

この追加は、新しい実行ファイルと説明、作図の「grid 未使用」の表示を用意するものです。
既存の RCWA 本体や計算関数の変更はありません。
