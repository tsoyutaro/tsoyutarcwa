# Archived Peng 2025 smoke outputs

These directories preserve earlier smoke runs made before the reproduction
study was reorganized and before the patterned annulus was explicitly named as
air.  They are retained for provenance only and must not be used as current
validation evidence.  Current results are stored one directory above.

`pre_fixed_mask_double_mapping/` contains intermediate double-map runs made
before the material discontinuities were fixed to computational support
curves.  Those runs can be non-passive and are retained only to document the
discarded implementation path.
