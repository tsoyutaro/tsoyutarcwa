# Fig. 3 の負の吸収の診断

`diagnose_fig3.py` は `reproduce.py` と同じディレクトリにあります。
既存ソルバーを変更せず、Fig. 3 の無損失誘電体を再計算します。
G は reproduce.py の値（現状 0.03）を使用し、実値を metadata.json に保存します。

```bash
python diagnose_fig3.py --orders 11,14,15 --grid 512 --identity-grid 1024 --device cuda --dtype complex128 --cascade algo2a --output-dir results/diagnostic_fig3_internal
```

まず ASR のみ調べる場合は `--profiles weiss2009` を追加します。
Redheffer と比較する場合は `--cascade redheffer` に変更します。
特異値分解には追加の時間とメモリが必要です。`--skip-conditions` で省略できますが、条件数は記録されなくなります。
実行ごとに一意な run_* ディレクトリを作成します。再開機能はありません。

各ケースの report.json に以下を保存します。

- x/y 偏光の全回折次数を合計した R, T, A。無損失なので A=0 が物理的基準です。
- PQW=Wkz²、QW=Vkz、PV=Wkz の残差。relative は ||a-b||/(||a||+||b||) です。
- 実際の計算が呼び出した `_solve` の呼出位置、後退誤差、右辺に対する残差。
- T、W、変換後 E/H、境界行列 A/core の最大・最小特異値と2ノルム条件数。
- 上下界面から独立に再構成した前進・後退モード係数の伝搬残差。
- 界面での電力流（x,y の順）。入射電力で規格化し、Cartesian と変換座標で比較します。

各ケースの modes.csv には全モードの kz、PQ 残差、前進モードの電力流を記録します。
モード番号は固有値ソルバーの順序です。異なる次数・実行間で同じモード番号を直接対応付けないでください。

解釈の目安：

- 固有値・Maxwell 残差が小さくても、エネルギー保存が保証されるわけではありません。
- 小さな後退誤差と大きな条件数が同時にある場合、解の前進誤差は大きい可能性があります。
- TW=E、TV=H は保存配列の整合性の確認です。変換式そのものの物理的正しさの検証ではありません。
- 負の Re(kz) だけで誤りと判断しません。Im(kz)、モード電力流、残差を併せて見ます。
- 変換座標の積分電力流では共変成分の外積と面積ヤコビアンが相殺します。有限次数の Fourier 変換後には電力流差が残り得ます。T のユニタリ性は要求していません。
- Cartesian の上下面で電力流が一致せず、変換座標内ではよく一致する場合は変換・切断の影響を疑います。ただし原因確定には追加検証が必要です。
- 複数の接続法で一致しても、共有する層 S 行列の問題は除外できません。

status=complete は診断処理の完了を意味し、物理的合格の判定ではありません。
途中結果は status=partial、例外は error.json に保存します。非有限数は JSON では null になります。
結果を共有する際は run_* ディレクトリ全体（metadata.json、各 report.json、modes.csv、あれば error.json）を渡してください。

保存済みの診断では、ASR の次数 11・14 で A=-0.132746・-0.092792、
変換行列 T の条件数は約 4.5e6・9.8e7 でした。固有値問題の残差はおおむね
1e-14 と小さく、Cartesian 境界で電力超過が大きくなります。
次数 15 の A は約 -0.000163 に減りますが、高次数 16・18 で再び増えています。
