# 20260806 RCWA: NV/ASR修正 v1.0.0（2026-10-05）

対象は共有ソルバーです。StudioのGUIやSVG描画を20260806研究コードへ移植した版ではありません。

NVでは \(\Delta=[1/\epsilon]^{-1}-[\epsilon]\)、\(P_{ab}=[n_an_b]\) に対し
\(\epsilon^F_{ab}=\delta_{ab}[\epsilon]+(\Delta P_{ab}+P_{ab}\Delta)/2\)
を使います。直交・斜交セル、同心円、native D6 starの両方の組立てへ適用しました。
これは [Weismann et al.式(6)](https://arxiv.org/pdf/1507.06364#page=6) の対称化です。
損失のある材料ではepsilonの複素共役を取らず、物理的な吸収を保持します。

ASRでは二方向それぞれのSchur構成を4ブロック完成させてから平均します。
行だけを混ぜる旧構成は使いません。これは有限次数の離散化の修正であり、
Weiss論文式を厳密にそのまま再現したとの主張ではありません。

磁場traceは電場traceと別のflux-dual変換を使用します。
\(T_E^\dagger C T_H=C/\sin\zeta\)、\(C=\begin{bmatrix}0&I\\-I&0\end{bmatrix}\)。
六方starと直交mirror sectorでは制限した変換から双対を解き、逆変換後の
丸め誤差のsector混入を避けます。長方形ASRにも同じ境界パワー条件を適用します。

縮約した内部場couplingは、減衰する位相を使うRedheffer合成で復元します。
厚い金属で極小な位相の逆数を取り、成長する誤差へ変える旧経路を除去しました。
全層の両方向境界残差を検査し、境界検査と同じ散乱解から場を復元します。
斜交ASRの縦場には共変波数K1/K2を使用します。

既存のrow-recomputation、反射専用auxiliary解放、縮約後P/Q解放、Jincの半径微分、
double/outer/core/shared-adaptive写像は保持します。old studies/最適化コードは変更していません。

## 判定の範囲

R+T=1や非負の吸収が確認できても、Fourier次数や写像・積分格子の収束は別です。
600 nmの高屈折率・金属試験は次数3,5,7と格子128,256のサンプルであり、
収束済みと判定していません。ASRとNVの収束速度を一般条件で順位付けする検査でもありません。

`field_xy`等の公開APIは有限Fourier係数を合成します。材料界面の局所電場を評価するときの
連続normal-D/epsilon回復や、物理格子での近接場収束・Joule体積積分収束は、
Studio側の専用後処理です。この共有ソルバー移植によって全断面の局所場が収束済みに
なったとは扱いません。六方独立Joule体積積分にも対応を追加していません。

以前の吸収率・収束表・最適化スコアは、この版で再評価してください。
材料や形状は同じでも、有限次数の離散化と界面整合が変わったため値が変わります。
従来Adamのmomentsや光学評価を新版へそのままresumeしません。
`--initial-run-dir`で形状パラメータだけを読み、新しいoutput-dirで再評価してから
必要なら追加探索します。既存checkpointのソースhash保護は解除していません。

GPU実機、クラスタでの高次数・多数層の完走、各論文の全図の再現は未検証です。
