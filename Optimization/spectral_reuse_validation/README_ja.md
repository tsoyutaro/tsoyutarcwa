# 追加高速化：波長間での形状・材料計算の共有

現在のD6専用版を基準に、一定屈折率材料で同じ形状を31波長にわたって計算する際の重複を除く試作。既存の43条件や進行中の計算は変更していない。六方格子・CPU・平均反射率とその一次勾配を対象とする。一定屈折率の係数共有に加え、PMMA分散では形状部分だけを共有する別経路を追加検証した。詳細は[PMMA分散の追加検証](PMMA分散_検証結果.md)を参照。

## 実測

CPUスレッド数1、complex128、M8、Q512、周期200 nm、高さ500 nm、3層、屈折率2.5。400〜700 nmを10 nm刻みの31波長で評価した。各層半径は周期で規格化して0.10/0.245/0.39。

| 計算 | 時間 | 現在のD6版に対する速度比 |
|---|---:|---:|
| 現在のD6版：31波長を逐次評価・逆伝播 | 69.88秒 | 1 |
| 共有する境界行列の準備も含む試作 | 8.73秒 | 約8.0倍 |
| 境界行列を準備済みの試作：次の形状評価 | 7.16秒 | 約9.8倍 |

**1回の測定値**。GPU、15層、実際のOptuna＋Adamフロー、最適化全体の所要時間ではない。共通のD6基底、Python起動、PyTorchのVJP初期化は両版の測定から除いた。試作の境界行列の準備は1.57秒で、同じ波長・材料・格子・次数の次の形状評価でも再利用できる。

R/Tの最大絶対誤差は1.64×10⁻¹³、3つの半径に対する平均反射率の勾配の最大絶対誤差は1.47×10⁻¹³。エネルギー残差は2.36×10⁻¹⁴。屈折率1.5と2.0でも、小規模なM2/Q48・3層・3波長で一致を確認した。

実行結果の生データは `verified_results/` 内のJSONに保存する。各結果には時間の内訳とソースのSHA256を含む。

## 時間がかかる場所

今回の31波長の基準計算69.88秒の内訳は、層の行列生成と固有値計算が53.21秒、逆伝播が13.49秒、cascadeとfluxが2.38秒、境界などの初期化が0.75秒だった。

現行コードは、1回のAdam stepで形状が固定されていても、各波長で材料行列・法線場・逆行列などを作り直す。一定屈折率材料では、この多くを波長間で共用できる。

## 共有する処理

垂直入射、固定形状、一定屈折率では、縮約したP/Qの波長依存性を、規格化波長t=λ/周期として

`P(λ) = P0 + t² P2`

`Q(λ) = Q0 + t² Q2`

と分けられる。P0/Q2は格子と次数で決まる。形状依存のP2/Q0を各層について一度作れば、各波長で同じ材料逆行列やNV法線場を作る必要がない。

固有値、層内伝搬の位相、Redheffer cascadeは各波長で評価する。S行列全体を波長間で共用する処理ではない。基準のFourier次数、Q、31波長、複素数精度を維持して比較した。

## 勾配の扱い

単に途中結果をdetachして使い回すと形状勾配を失う。試作は、各波長でP2/Q0に対するcotangentを計算・加算し、最後に元の形状依存グラフへ一度だけvector-Jacobian productを適用する。

これにより31波長すべての固有値・cascadeの逆伝播グラフを同時に保持せず、平均反射率の一次勾配を計算できる。[PyTorchのgrad_outputsとVJPの説明](https://docs.pytorch.org/docs/2.8/generated/torch.autograd.grad.html)。本番への接続には、softmax logits、checkpoint、監査・再開などの経路についても追加検証する。

## 再現コマンド

このフォルダ内で実行する。Python/PyTorch/torcwaは前回のD6検証と同じ依存を用いる。Optunaは不要。

```powershell
# 小規模な一致確認
python benchmark.py --order 2 --grid 48 --layers 3 --output results/small.json

# 上記31波長の測定
python benchmark.py --order 8 --grid 512 --layers 3 --wavelengths 400:700:10 --output results/M8_Q512_31waves.json
```

不一致時は終了コード1、合格時は0。今回の試作はCPU専用とし、CUDA指定を拒否する。

## 適用範囲

一定屈折率1.5/2.0/2.5の39条件に対して有力な方法。正方格子も同じ波長依存性を持つが、この試作の検証対象は六方格子に限る。

PMMAではn(λ)が変わるため、P2/Q0や材料逆行列を全波長でそのまま共用できない。形状のFourier係数とNV法線射影、格子と境界の準備などを分けて共有する設計が必要。

## その次の候補

1. 少ない波長・低い次数から始め、良い形状を現行の31波長・M8で仕上げ、M16と高密度波長で検証する段階的最適化。7波長なら各stepの波長ソルバー呼出数は31波長の約1/4.4になるが、目的関数と探索経路が変わるため、同じ最適解を保証する見積もりではない。
2. 波長方向のGPUバッチ処理。現在は1波長ずつ解く。小さな行列をまとめることでGPUの稼働率を上げる余地がある。custom eig、安定化solve、勾配、メモリ上限に合わせた改修が必要で、GPUでの倍率は未測定。[PyTorchのバッチ化機能](https://docs.pytorch.org/docs/2.8/generated/torch.vmap.html)。
3. 半径に依存しない最寄り周期像、格子距離、Fourier差分のキャッシュ。法線場のtaperには半径依存性があるため、法線射影行列全体を全Adam stepにわたって固定することはしない。

## PMMA分散の追加検証

`benchmark_pmma.py` は波長ごとのn(λ)を突起と基板へ適用し、形状係数とNV法線射影だけを共有する。材料行列・逆行列・P/Qは各波長で再計算する。M2/Q48の5/10/15/20層と、M8/Q512/31波長の5層で基準との応答・勾配の一致を確認した。測定値と適用範囲はPMMA分散_検証結果.mdに記載。
